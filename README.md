# AI Textbook Assistant

A Retrieval-Augmented Generation (RAG) system that:
- Ingests textbook PDFs
- Supports chat-based Q&A
- Generates structured lesson plans grounded in textbook content

## Features
- PDF upload and indexing
- Semantic search with FAISS
- Chat interface
- Lesson plan generation (topic + chapter based)

## Tech Stack
- Python, Flask
- LlamaIndex
- FAISS
- Ollama
- HTML, CSS, JavaScript

## Usage
1. Upload a textbook PDF
2. Wait for indexing to complete
3. Use Chat or Lesson Plan tabs

## Notes
- Vector indexes and PDFs are excluded from version control
